# Public repository scope

This repository is an offline domain demonstration. All included fixtures and demo values are fictitious. It contains no authentication service, credential loader, bank connector, deployment configuration or production dataset.

The public history starts with an allowlisted export; the private application's Git history is not included. Do not add personal exports or configuration files to this repository. `.gitignore` is a convenience, not a security boundary.

Tests and static scans support a bounded review of the published files. They are not a guarantee of zero defects or a production security audit. If you find a defect, use a minimal synthetic reproduction; do not post credentials or personal data in an issue.
